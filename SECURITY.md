# Security reporting

Do not post credentials or real email content in public issues. Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/khalifehbasiri/Job-Tracker-AI/security/advisories/new).

This early developer release is supported on the current main branch. There is no signed installer or automatic update mechanism. It uses OS credential storage, read-only mailbox permissions, constrained model output, plain-text email rendering, and app-level API spending reservations. These controls do not encrypt the local database or replace provider billing limits.
