Job Tracker AI - self-configured edition

Bring your own OpenAI API key and Google
Desktop OAuth registration or Microsoft Application client ID. The app includes
an offline setup guide and first-run wizard. No developer credentials are supplied.

AI processing sends selected email text to OpenAI and uses your API credits.
Automatic processing is off by default. Manual tracking and Excel export need
no AI key. Your local database is not encrypted by this application.

This build is unsigned. AI classification uses OpenAI's public-beta Decisions
API and requires access through your OpenAI project. Provider policies and
work/school account consent restrictions can affect sign-in. Automated tests
do not guarantee compatibility with every provider account or model accuracy.
Uninstalling removes the program but preserves records and OS credentials.
Close the application before upgrading or uninstalling. For v0.2.0 and older, use Quit in the tray menu.
