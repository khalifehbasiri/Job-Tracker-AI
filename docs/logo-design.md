# App logo

The envelope/document represents incoming application emails, the checkmark represents
tracking, and the small sparkle represents AI classification. The forest green and
cream palette matches the desktop dashboard. Artwork was generated using the built-in
Image Generation tool, then exported to Windows icon sizes with `scripts/build_icon.py`.

- App artwork: `src/job_tracker/assets/logo.png`
- Windows icon: `src/job_tracker/assets/logo.ico` (16, 24, 32, 48, 64, 128, 256 pixels)
- README artwork: `docs/images/logo.png`
- Background: transparent outside the rounded tile.

## Generation prompt

Create a polished desktop application logo/icon for an open-source application called
Job Tracker AI. Icon only, no text or letters. A simple, distinctive cream-colored
envelope/document with a confident green checkmark, combined with one small four-point
AI sparkle in the upper right, on a dark forest-emerald rounded square tile. Minimal
flat vector-like geometry, warm cream #F4F5EF, dark forest #173F36, fresh mint accent
#86C9AF. Strong balanced silhouette legible at 24px, professional and calm, subtle
precision, generous padding. No gradients, no photorealism, no shadows, no fine detail.
Square composition. Transparent outside the rounded square tile; tile is opaque.
Deliver a single crisp high-resolution icon suitable for a Windows app, tray and GitHub README.
